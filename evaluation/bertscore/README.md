# BERTScore Evaluation Datasets

This directory contains CSV files for evaluating PRISM-generated responses using `PRISM_BERTScore_Evaluation_Colab.ipynb`.

## Candidate Responses

- `RAG_conversation_QA.csv`: Responses generated using the RAG configuration.
- `nRG_conversation_QA.csv`: Responses generated using the non-RAG configuration.

## Reference Answers

- `gold_qa_gpt.csv`: Reference answers generated by ChatGPT.
- `gold_qa_claude.csv`: Reference answers generated by Claude.
- `gold_qa_gemini.csv`: Reference answers generated by Gemini.
- `gold_qa_draft.csv`: Additional reference-answer dataset.

Each CSV contains 30 question–answer pairs with the columns `No`, `Question`, and `Answer`.

## Usage

1. Open `PRISM_BERTScore_Evaluation_Colab.ipynb` in Google Colab.
2. Upload the candidate and reference CSV files.
3. Run the notebook and select the datasets to compare.
4. Calculate BERTScore, ROUGE-L, and BLEU.
5. Export the detailed and summary evaluation results.

## Reproducibility

The notebook provides an executable evaluation workflow. Exact reproduction of previously reported scores depends on matching the original evaluation settings and software environment.
