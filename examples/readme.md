# Q&A Generation — Example Outputs (2026-10-15)

## Overview

This directory contains example CSV files generated on October 15, 2026, during an execution test of `PRISM_QA_Generation_Colab.ipynb` in Google Colab.

These files are provided to illustrate the output format and demonstrate the Q&A generation workflow.

## Files

- `gold_qa_draft.csv`: Contains 30 generated question–answer pairs.
- `gold_qa_evidence_audit.csv`: Contains the generated Q&A pairs together with supporting evidence, page information, and review status.

## Important Notice

**These CSV files are not the Q&A dataset used for the evaluation reported in the PRISM manuscript.**

They were generated separately for testing the Q&A generation notebook and should not be used to reproduce the evaluation results reported in the paper.

The Q&A dataset used in the manuscript is documented separately in `QUESTIONS.md` and `ANSWERS.md` in the repository root directory.

## Reproducibility

The example files were generated by executing `PRISM_QA_Generation_Colab.ipynb` in Google Colab on October 15, 2026.

The notebook can be used to generate Q&A datasets from user-provided research papers. Generated questions and answers may vary depending on the input document, model configuration, and execution environment.
