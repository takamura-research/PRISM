# Q&A Generation Workflow Validation (2026-10-15)

## Overview
This directory contains CSV files generated on October 15, 2026, during an execution test of `PRISM_QA_Generation_Colab.ipynb` in Google Colab.

These files are provided to document the execution test, illustrate the output format, and demonstrate the Q&A generation workflow.


## Files
- `gold_qa_draft_validation.csv`: Contains 30 generated question–answer pairs.
- `gold_qa_evidence_audit_validation.csv`: Contains the generated Q&A pairs together with supporting evidence, page information, and review status.


## Important Notice

**These CSV files are not the Q&A dataset used for the evaluation reported in the PRISM manuscript.**

They were generated separately to verify the execution of the Q&A generation notebook and should not be used to reproduce the evaluation results reported in the manuscript.

The Q&A dataset used in the manuscript is documented separately in [`QUESTIONS.md`](../../evaluation/QUESTIONS.md) and [`ANSWERS.md`](../../evaluation/ANSWERS.md).


## Reproducibility
The files were generated by executing `PRISM_QA_Generation_Colab.ipynb` in Google Colab on October 15, 2026.

The notebook can be used to generate Q&A datasets from user-provided research papers. Generated questions and answers may vary depending on the input document, model configuration, and execution environment.
